# UCI Adult Feature Engineering Assignment

## Run

```bash
python -m pip install -r requirements.txt
python adult_feature_engineering.py
```

The first run downloads the official UCI `adult.data` and `adult.test` files and caches it under `data/`. The program then creates the EDA figures, missing/outlier summaries, experiment metric table, feature-importance table, Markdown report, and Korean PDF report in `outputs/`.

## Experiments

- Base: most-frequent imputation, ordinal encoding, no scaling, no feature selection
- Exp-1: mean numeric imputation, one-hot encoding, StandardScaler
- Exp-2: median numeric imputation, ordinal encoding, MinMaxScaler, Random Forest selection
- Exp-3: most-frequent imputation, one-hot encoding, RobustScaler, Random Forest selection
- Models: Logistic Regression and Random Forest
- Metrics: accuracy, precision, recall, F1, ROC-AUC

The sklearn estimators cannot consume raw strings, so “Base” uses ordinal encoding as the minimum runnable baseline. All preprocessing is fit inside a `Pipeline` on the training split to prevent data leakage. Split: 80:20, stratified, seed 42.
